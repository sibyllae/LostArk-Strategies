# ARKESIA CODEX · LostArk Strategies (失落的方舟・戰術與收集快查手冊)

專為《失落的方舟》（Lost Ark）冒險者打造的低眩光黑曜石（Obsidian Lookup）雙螢幕快查手冊與本機進度追蹤工具，完整涵蓋至 **2026 T4 卡達魯姆群島＆暗影襲擊戰紀元**。

## 🌟 核心功能模組 (Core Modules)

*   **I · NPC 好友度圖鑑 (Rapport Archive):** 收錄各大陸與島嶼重點 NPC 五階獎勵、四維門檻（知性／膽量／魅力／親切）、點數預算上限／區間篩選與本機完成標記。
*   **II · 大陸冒險之書 (Adventurer's Tome):** 20 座大陸 10%～90% 里程碑橫軸、2026 卡達魯姆篇章說明，並與伊格涅亞標誌即時連動。
*   **III · 收集品互動追蹤 (Relic Collectibles):** 巨人心臟、血爪海圖（#1／#2 精確碎片時間與航線）、奧菲斯之星、島之心、偉大藝術品、伊格涅亞、記憶八音盒、航海冒險物（51 張含薩克利亞香爐）與世界樹（120 片）／摩可可（1450+ 顆），支援取得管道分類快篩與本機記憶。
*   **IV · 副本血條機制與每週 3 本帳本 (Raid Mechanics & Gold Ledger):** 涵蓋 T3 伐爾坦至 T4 卡札羅斯第 1～4 幕與終幕、地平線大聖堂（1～3 階全額綁金）、暗影襲擊戰「賽爾卡」與 1750–1780「貝爾加丁」（普／困／惡夢），整合 **各關首領 `x###` 血條機制一圖流、艾斯特聯手技、推薦戰鬥道具** 與 1～6 角週收排程試算。
*   **V · 養成與配裝戰術 (Ark Passive & Gear):** T4 飾品研磨精確數值、T4 手鐲 11 大詞條、**16 大 T4 遺物刻印書倍率與能力石格數表**、**T4 寶石 Lv.1–10 轉換表與精煉黃金斷點矩陣**、八大減負養成系統（含 1750 護腕）與 19 洲流浪商人必蹲傳說卡。
*   **VI · 百科速查台 (Tactical Encyclopedia):** 15 張獨立速查表（裝等路線、T4 守護者、13 大全職業與新職流派、方舟星圖 17 點、戰鬥道具、悟性點、技能點、卡組與 6 大種族增傷表、技能符文、**大航海船隻船員〔含 2026 盧米納斯號〕**、**跨服譯名與 T4 改制對照表**、**T4 生活採集與阿比多斯融合精算**、樂譜與艾波娜委託）。
*   **鍵盤優先全域快搜 (`Q` / `/` / `Ctrl+K`):** 跨全站副本血條、刻印、寶石、手鐲、NPC、島嶼、船隻與跨服俗稱即時模糊檢索直達錨點。

## 🛠️ 技術棧與設計架構 (Architecture)

*   **UI/UX 設計系統:** Obsidian Lookup Design System (`.agents/skills/uiux/SKILL.md` — `#121212` 低眩光黑曜石階層、1px 細邊線、`tabular-nums` 等寬數字、三斷點 3-Zone 水平資料卡、差異高亮比較表、URL 同步複合篩選器、行動版 `44×44px` 觸控與 PWA 返回輔助)
*   **前端框架:** React 18 + TypeScript 5
*   **路由與狀態:** React Router v7 + Redux Toolkit (RTK Query)
*   **樣式與元件:** Tailwind CSS + Ant Design 6
*   **建構工具:** Vite 5 + ESLint 9
